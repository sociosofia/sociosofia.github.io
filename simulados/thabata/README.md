# Simulado SARESP 2026 — professora Thabata

Espaço reservado para o simulado da professora Thabata.

**Estado:** em preparação. Ainda não publicar o endereço para estudantes.

## Publicação

1. Baixe o arquivo `index.html` preparado para o Sociosofia (16 MB, 240 questões convertidas para WebP).
2. Nesta pasta do repositório, use **Add file → Upload files** e envie o `index.html` (não o HTML original de 50 MB).
3. Abra `https://sociosofia.github.io/simulados/thabata/` e confira a prova antes de distribuir.
4. No Cloudflare Worker `saresp-thabata-2026-api`, configure a variável **secreta** `ADMIN_KEY` com a chave administrativa fornecida separadamente pelo responsável. Nunca coloque essa chave no GitHub.
5. Consulte `https://saresp-thabata-2026-api.luizvjj.workers.dev/admin`, informe a chave e clique em **Abrir recebimento** apenas após os testes.

**Armazenamento:** Cloudflare D1 `saresp-thabata-2026`. O painel exporta CSV; não há conexão com Google Sheets nem gabarito/correção automáticos nesta versão.

**Privacidade:** endereço GitHub Pages é público mesmo quando divulgado só internamente. Confirmar autorização escolar para uso das questões e adotar o mínimo necessário de dados pessoais. O painel exige a chave administrativa; não publicar/exportar nomes ou respostas no repositório.
